# DramaFlash

Clickable prototype of the DramaFlash beta app: home feed, vertical player with the episode lock after the cliffhanger, and the unlock flow (coins / subscription / rewarded ad).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Build

```bash
npm run build
```

The static build is written to `dist/`. It uses relative paths and hash routing, so `dist/index.html` can be opened directly from disk or hosted on any static server.
